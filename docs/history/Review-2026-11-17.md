# Review 2026-11-17, settled

Eight reviews of the whole code base at `2120959` (v0.3.5 and four commits), one topic
each: memory, performance, robustness, the hot path, hacks and workarounds, happy and sad
path tests, untrusted input, and whether `mwt.info`, the README and CAVEATS.md match the
code. Each finding was checked against the code before it was acted on; the line numbers
below are those of `2120959`.

**Reproduced** means seen by feeding the VT core, running mwt under a headless sway or
xterm 407 in Podman. **Read** means confirmed from the code only.

Nothing was found that output from the pty can use to corrupt memory or to inject input:
replies carry no text the program chose, and a paste cannot close its bracket.


## Fixed

Each with a test that fails without the fix, unless said otherwise.

### Bugs

- Reproduced: bold and italic drew nothing for characters only the regular face has,
  1153 of them with DejaVu Sans Mono (`font.c` `render`, the `dup` check in
  `find_fallback`). `02675ea`, `tests/font_style.c`.
- Reproduced: a screen row written while scrolled back was redrawn in the wrong row and
  the one showing it stayed stale; the VT core marked screen rows, mwt draws rows shown.
  Found while working on the redraws, not by a review. `af4a591`.
- Reproduced against xterm 407: 1047 cleared the alternate screen on entering instead of
  leaving; EL, ECH and ED 0 to 2 kept a pending wrap; `ESC =`, `ESC >`, `ESC H` and
  `ESC Z` dropped one and DECRC did not restore it; DECXCPR ignored origin mode; digits
  past the 24th parameter were added to the last (`0;` x24 `3;1m` set red); SGR 8 left
  underline and strike visible. `c717150`.
- Reproduced: newline mode was set and reported, but Return sent CR alone. `eca2fd5`.
- Reproduced: C1 controls in UTF-8 (`\xc2\x9b`) were pasted; a program that does not
  read was given pastes without limit; Latin-1 was counted before it doubled as UTF-8;
  mwt's own selection skipped the limit. `3b90a18`.
- Reproduced: a repeat delay of 0 turned repeat off; the shell got fds mwt was started
  with; without a first buffer mwt ran on unseen; a zoom past 2 GiB stopped drawing; the
  DECRQCRA sum overflowed an int (UBSan reported it, `make check` passed, now it fails on
  any sanitizer report); titles kept DEL and C1. `34ceae7`.
- Read, as sway does not show them, so without a failing test: buttons held and focus
  when a device leaves the seat, the repeat while the menu is open, NULL from libwayland
  constructors, `kb_keymap` freeing the old state before the new one existed. `34ceae7`.
- Reproduced: `have_terminfo` looked through eight entries of `TERMINFO_DIRS`; without a
  pidfd, jobs keeping the pty open kept mwt for good. `dfe446c`.

### Performance

Measured with `tests/profbench.c` and `make profile`, 200x55 at 1080p.

| | before | after |
|---|---|---|
| VT core, text (MB/s) | 122 | 423 |
| VT core, `yes` (MB/s) | 50 | 80 |
| VT core, full screens (MB/s) | 153 | 945 |
| damage on a focus change or a drag step | whole window | at most three rows |
| a screen of code points no font has, 296 fonts | 0.38 s | 0.05 s |

The ASCII fast path (`f8fc625`) gives identical `vtdump` state on 1686 runs over the
recordings and 3000 random inputs. `cup` reads about 10 % lower, but so does the old core
with an unused function added; with aligned functions both are equal. The redraws and the
fallback list are `1642155`, checked by `pixel.py test_damage` through `WAYLAND_DEBUG` and
`tests/font_lookup.c`, which counts fontconfig calls.

### Tests

`make replay` compares end states with `tests/replay.sums` (a bug planted in DEC graphics
showed in 31 files, before in none); the fuzz oracles compare replies, titles, history
and saved cursors (a planted bug failed 102 checks, before none); `evil.sh` checks exact
values, protocol errors and what CAVEATS.md promises; `tests/lib.sh` replaces four copies
of the harness and waits for the window instead of 1.5 s; `keyboard.py` and `mouse.py`
check that something came before that nothing more does; `tests/args.sh` runs the command
line in `make check`. `792728c`, `c2da0fb`, `97673b2`, `6d4f619`.

### Workarounds

Tunables in `config.h` (double click time, zoom limits, touchpad step) and the esctest
switch there too, one table for setting private modes and for DECRQM (1048 had drifted),
named constants for the rest. `dfe446c`.


## Documented in CAVEATS.md

The shell's environment as given (`TMUX` and the like), tab stops reset on resize,
DECRQM 1048 unknown, no blinking cursor, mode 1007 always on, when Shift+PgUp, PgDn,
Home and End reach the program, what the `xterm-256color` fallback promises, the zoom
limit, only the first seat, and no frame without xdg-decoration (`fa0b03a`, `34ceae7`,
`c77d341`).

## Kept as they are

- DECXCPR answers without the page: esctest asks for it from VT level 4, mwt reports 2.
- 24 parameters, the rest dropped as DEC says; xterm keeps 30.
- Bidi and format characters stay in titles: legitimate titles have them.
- The pidfd fallback stays, as seccomp may deny `pidfd_open`; `evil.sh no_pidfd` runs it.
- `font.c`'s cache limits can be set by the test that includes it
  (`tests/font_cache.c`); a seam for one test, not a runtime option.
- The `vinput` layout patch in `container-run.sh` stays, now failing loudly when mwc's
  line changes; the clean fix is in mwc.
